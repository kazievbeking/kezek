# Отчёты и формулы

Runtime 1.1.0: фильтры сотрудника, услуги и филиала; столы в интерфейсе убраны. Фильтр deskId в API оставлен только для исторических данных. Новые смены и интервалы не привязаны к столу. См. EMPLOYEE-SERVICES.md.

Фильтры: период, филиал (или все доступные), сотрудник, стол, услуга. COMPANY_ADMIN видит все филиалы своей компании. BRANCH_ADMIN — только назначенные; STAFF принудительно ограничен собственным userId и доступными филиалами. Чужие ID не расширяют область доступа.

Выбор родительской услуги включает её подуслуги по текущему дереву филиала. Подробнее SERVICES.md.

Календарные даты интерпретируются сервером в часовом поясе компании (`settings.timezone`); конец выбранного дня включается через начало следующего дня. ISO timestamps задают точные UTC-границы. Интервал — `[from,to)`, максимум 366 дней. Часовой пояс явно возвращается и отображается в отчёте. Группировка по часам использует этот же пояс, в том числе при общей выборке. Для талона может использоваться разрешённый часовой пояс филиала; для сводного отчёта осознанно используется единый пояс компании.

Когорта отчёта — талоны с issuedAt в выбранном периоде:

- Выдано: количество UUID талонов когорты.
- Ожидают: её талоны WAITING на момент запроса.
- Завершено: UUID в COMPLETED; передача не увеличивает общее число завершённых клиентов.
- Неявки / отмены: NO_SHOW / CANCELLED.
- Среднее ожидание: среднее `(firstCalledAt − issuedAt)` по вызванным талонам. Повторные вызовы и передачи не сбрасывают calledAt.
- Среднее обслуживание: по каждому завершённому талону сумма его закрытых интервалов; затем среднее по завершённым талонам.
- Уникальные клиенты сотрудника: distinct ticketId его интервалов обслуживания. Один талон может учитываться у нескольких участвовавших сотрудников.
- Завершённые сотрудником: COMPLETED с финальным userId этого сотрудника. Без фильтров сумма равна общему числу завершённых талонов компании.
- Время участия: сумма `(endedAt − startedAt)` его закрытых интервалов. Ожидание принятия/начала обслуживания получателем не является обслуживанием.
- Входящие/исходящие передачи: принятые запросы для талонов выбранной когорты по toId/fromId.
- Загруженность по часам: количество выдач по локальному часу issuedAt.
- Смены и паузы: сумма пересечений интервалов с `[from,to)`, открытый интервал ограничен текущим временем.

Фильтр сотрудника/стола включает талон, если он назначен ему сейчас/финально или имеет его интервал; время затем считается по соответствующим интервалам. При фильтре сотрудника среднее обслуживание отражает его долю участия в выбранной когорте. Отдельная статистика текущей смены использует интервалы/завершения начиная со старта смены и учитывает клиентов, выданных раньше её начала.

Есть общие показатели, отдельные строки филиалов, таблица сотрудников, история смен и график выдач по часам. История в ответе ограничена последними 200 сменами / 500 интервалами, агрегаты считаются по всей выборке. Полноценная постраничная история и нагрузочная оптимизация больших периодов — дальнейшее развитие.

CSV: UTF-8 BOM, `;`, экранирование кавычек и нейтрализация формул. XLSX: строки и числовые значения с локализованными заголовками. Язык экспорта задаётся параметром locale (ru/kk/en). Файл содержит персональные данные и подлежит правилам хранения заказчика.
