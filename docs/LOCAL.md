# Локальная демонстрация на этом компьютере

Корень: `D:\OSPanel\domains\kezek`. Это новая самостоятельная сборка; старые БД не подключаются.

Адреса:

- Супер-админка: http://localhost:3002/owner
- Компания: http://localhost:3001/admin
- Сотрудник: http://localhost:3001/staff
- Терминал: http://localhost:3001/terminal
- ТВ: http://localhost:3001/display
- Регистрация компьютера: http://localhost:3001/workstation

Логины и текущие пароли находятся в `.local/demo-credentials.json` → accounts. Владелец: `owner`, компании: `admin1`, `admin2`, администраторы филиалов: `manager11`, `manager12`, `manager21`. Остальные сотрудники перечислены в этом же файле. Каждый временный пароль индивидуален; первый вход требует его смены. Автоматическая браузерная проверка уже сменила пароль `admin1` и `manager11`, сохранив актуальное значение в этом локальном файле. Не используйте демо-пароли на внешнем сервере.

В `tokens` — два демонстрационных токена: `1234-5678` и `2345-6789`. Первый относится к первой компании, второй — ко второй. Вводить один раз в отдельном профиле/браузере терминала и ТВ. Cookie роли устройства и пользователя различаются. Если в одном профиле войти устройством, его cookie заменит пользовательскую Runtime-сессию; для разных ролей нужны разные профили. Владелец использует отдельную Control Plane cookie.

## После перезагрузки

В PowerShell из корня проекта добавить локальный Node в PATH:

```powershell
$env:Path="$PWD\.tools\node-v22.16.0-win-x64;$env:Path"
node .tools/start-v2-postgres.mjs
```

Не запускать второй экземпляр, если PostgreSQL уже слушает 55433. В двух других терминалах:

```powershell
node --env-file=.env apps/runtime-api/dist/index.js
node --env-file=.env apps/control-api/dist/index.js
```

Для запуска без видимого окна можно использовать `Start-Process -WindowStyle Hidden` с теми же аргументами и WorkingDirectory корня проекта. Проверить `/api/health` на обоих портах. В текущей проверке оба API запущены отдельно. Процессы не установлены как системные службы: после перезагрузки нужен запуск.

PostgreSQL демонстрации: `127.0.0.1:55433`, базы `kezek_v2_runtime`, `kezek_v2_control`; тесты используют отдельные `_test` базы и новые схемы. Пароль и connection strings лежат только в закрытых `.local/db-secret` и `.env`. Не публикуйте их. `.tools` — локальные инструменты тестирования; для постоянной установки нужен штатный PostgreSQL/Compose, см. INSTALLATION.md.

## Изменения и проверки

```powershell
npm.cmd run check
npm.cmd test
npm.cmd run test:ui
npm.cmd run test:services
npm.cmd run test:owner-access
npm.cmd run test:restart
```

На Windows перед `npm run build` остановить процессы API: Prisma engine DLL блокируется работающим Node. Затем собрать, применить новые миграции и запустить API снова. `bootstrap` повторно не сбрасывает пароли и данные.

`test:ui` требует установленный Microsoft Edge по стандартному пути, работающие API и локальный credentials file. Проверка создаёт тестовых сотрудников и талоны; результаты и скриншоты — `artifacts/ui`. Физическая печать заменяется контролируемой имитацией браузерного диалога. `test:restart` запускает дополнительный Runtime на 33021, создаёт талон, подтверждает print lease, завершает процесс и проверяет сохранение сессии и результата после запуска.

Настройка обновлений оставлена выключенной. Доступ владельца к Runtime также выключен по умолчанию; для явной проверки — `ALLOW_OWNER_ACCESS=true`, перезапуск Runtime и одноразовый signed permit из Control Plane. Внешний хостинг, домен и GitHub ещё не подключены.
