# Демонстрация Kezek для инвестора

Kezek — веб-платформа электронной очереди для нескольких компаний. Структура: компания → филиалы → точки обслуживания. Каждая точка имеет собственную очередь, услуги, сотрудников и устройства.

## Что показать

1. В панели владельца — компании, структуру филиалов и точек, выдачу регистрационных токенов.
2. В админке компании — вложенные услуги, назначения сотрудникам и разграничение доступа.
3. На терминале — выбор услуги и получение номера.
4. В рабочем месте сотрудника — начало смены, вызов и завершение обслуживания.
5. На дисплее — вызванные и ожидающие номера только своей точки.
6. В отчётах — результаты по филиалу и точке, выгрузку CSV/XLSX.
7. Переключение RU/KK/EN и работу локальной очереди без Control Plane.

## Что даёт этот репозиторий

Исходный код, миграции, инструкции запуска, тесты и PDF. Пароли, ключи, регистрационные токены, базы данных и резервные копии не публикуются. Возможности и ограничения перечислены в [STATUS.md](STATUS.md).

GitHub хранит проект. Само размещение исходников не запускает Node.js API и PostgreSQL. GitHub Pages не является средой исполнения этой серверной системы.

## Показ без VPS и статического IP

Можно показать работающую локальную установку через демонстрацию экрана. Для самостоятельного доступа инвестора по ссылке потребуется отдельное размещение либо временный HTTPS-туннель к специально подготовленной демонстрационной установке. Для туннеля компьютер и интернет должны оставаться включёнными. Этот репозиторий сам туннель не создаёт.

Для публичной демонстрации используйте отдельные тестовые данные и отдельные учётные записи. Суперадминистратор нужен для показа владельцем; инвестору достаточно заранее выбранных ролей. Подготовка внешней демонстрации и проверка HTTPS, cookies, разрешённых origin и WebSocket выполняются отдельно.
